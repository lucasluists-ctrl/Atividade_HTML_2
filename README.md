# 🌊 Atividade HTML — Animais Marinhos

Projeto desenvolvido como atividade acadêmica com o objetivo de praticar os fundamentos do **HTML** e a criação de páginas interligadas por meio de links.

O site apresenta informações sobre diferentes grupos de animais marinhos, permitindo navegar entre as categorias.

## 🐠 Categorias

- 🐟 Peixes
- 🐋 Mamíferos
- 🦀 Crustáceos
- 🐙 Moluscos

## 📚 Objetivos da atividade

- Praticar a estrutura básica do HTML;
- Criar diferentes páginas HTML;
- Utilizar links para navegação entre páginas;
- Trabalhar com imagens;
- Utilizar elementos como títulos, parágrafos, listas e formulários;
- Organizar arquivos e pastas de um site.

## 🛠️ Tecnologias utilizadas

- HTML5
- Git
- GitHub
- Visual Studio Code
